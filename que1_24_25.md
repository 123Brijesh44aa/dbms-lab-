## 🧠 Part 1: Explaining the Concepts (The "14-Year-Old" Guide)

### 1. What is a Convolutional Neural Network (CNN)?

Imagine you are looking at a picture of a cat. Your brain doesn't look at all the pixels at once. Instead, your eyes first detect **edges**, then **shapes** (like triangles for ears), and finally **complete objects** (a cat face).

A CNN does exactly this using a few special layers:

* **CONV Layer (The Feature Finder):** Think of this as sliding a small magnifying glass (called a **filter** or **kernel**) across the image. If the image is $128 \times 128$ pixels, a $5 \times 5$ filter looks at small $5 \times 5$ chunks at a time to find edges or patterns.
* **Stride:** How many steps the magnifying glass moves at a time. Stride 1 means it moves 1 pixel at a time.
* **Padding ("Same"):** When a filter slides over an image, the edges get less attention than the middle. To fix this, we wrap the image in a "border" of zeros (like adding a picture frame). **"Same padding"** means we add just enough border so that the output image size stays *exactly the same* as the input size after convolution.


* **POOL Layer (The Shrinker):** Images have a lot of pixels, which makes the computer work too hard. A Max Pooling layer shrinks the image by looking at a small area (like $3 \times 3$) and keeping *only* the biggest, brightest number (the most important feature), throwing away the rest.
* **FC Layer (Fully Connected / The Decider):** After shrinking and finding features, we flatten the image into a long line of numbers and hand it over to normal neurons. Every neuron here connects to every single number from the previous layer to make the final guess (e.g., "Is it a cat, dog, or car?").

### 2. Formulas We Need to Know

To calculate sizes, we use these two simple recipes:

* **For Convolution with "Same" Padding:** 
$$\text{Output Size} = \text{Input Size}$$


* **For Pooling (or custom steps):** 
$$\text{Output Size} = \left\lfloor \frac{\text{Input Size} - \text{Filter Size}}{\text{Stride}} \right\rfloor + 1$$

### 🌋 1(d) Vanishing and Exploding Gradients

When a network is very deep, it passes information backwards during training (backpropagation) using multiplication.

* **Vanishing Gradients:** If you multiply numbers smaller than 1 (like $0.1 \times 0.1 \times 0.1...$), the number becomes practically **zero**. The deeper layers stop learning because their updates are too small.
* **Exploding Gradients:** If you multiply numbers greater than 1 (like $2 \times 2 \times 2...$), the numbers become **infinitely large**, causing the model to crash (`NaN` errors).

### 📧 1(f) Spam Classification Activation Issue

* **Setup:** $\hat{y} = \sigma(\text{ReLU}(z))$
* **Let's analyze:** * If $z$ is negative (e.g., $-5$), $\text{ReLU}(-5) = 0$.
* Then, $\sigma(0) = 0.5$.
* The rule says: if $\hat{y} \ge 0.5$, it's **Spam**.
* Because $\sigma(0)$ is exactly $0.5$, any negative input $z$ will yield an output of $0.5$, classifying it automatically as **Spam**. It can never confidently output non-spam (< 0.5) for negative inputs!
* Furthermore, if $z \le 0$, the gradient of ReLU is 0, which completely stops learning.


* **Correct Option:** **C. The gradient of the ReLU function is zero for negative z, which may block gradient flow during training.** (This is the famous "Dying ReLU" problem).

### 📊 1(g) Softmax and Cross-Entropy Calculation

Formula for Softmax: $P(x_i) = \frac{e^{z_i}}{\sum e^{z_j}}$

1. Calculate $e^z$:
* $e^2 \approx 7.389$
* $e^1 \approx 2.718$
* $e^0 = 1$

* $P(\text{Class 1}) = \frac{7.389}{11.107} \approx \mathbf{0.665}$

## 🧠 Part 1: Explaining the Concepts (The "14-Year-Old" Guide)

### 1. What is a Recurrent Neural Network (RNN)?

Imagine reading a sentence: *"The clouds are in the ________."* Your brain instantly fills in the word **"sky"**. How? Because you remembered the previous words (*clouds*, *are*, *in*).

Standard neural networks can't do this; they treat every input like a completely fresh slate, forgetting everything they just saw. An **RNN**, however, has a **memory loop**. It processes data step-by-step (sequentially) and passes what it learned from the past into the future.

* **The Hidden State ($h_t$):** This is the RNN's "memory notebook." At timestamp $t$, it looks at the current word ($x_t$) **and** its old memory notebook from the previous second ($h_{t-1}$). It combines them to update the notebook into a new memory state ($h_t$).
* **The Problem with RNNs:** Because they keep multiplying old memories over and over, they have a short attention span. If a sentence is too long, they forget the beginning. This is called the **Vanishing Gradient** problem.

### 2. Enter LSTM: The Super Memory Upgrade

To fix this short attention span, scientists invented **LSTM (Long Short-Term Memory)**. Think of it as an RNN but with a highly organized filing system containing specialized "gates":

* **Cell State ($C_t$):** This is like a long conveyor belt running straight down the entire chain. It holds the core, long-term memories. Information can flow down it unchanged very easily.
* **Forget Gate ($f_t$):** This gate looks at the new input and decides what useless old stuff to throw away from the conveyor belt. (Outputs a number between 0 = "forget everything" and 1 = "keep everything").
* **Input Gate ($i_t$):** This gate decides what *new* important information from the current step should be added onto the conveyor belt.
* **Candidate State ($\tilde{C}_t$):** A temporary bucket of new ideas created from the current input, waiting to be filtered by the input gate before touching the main conveyor belt.

### 🧩 2(a) Working Procedure of an RNN

To explain how an RNN processes sequential data over time for a 4-mark question, break it down into these key procedural steps:

1. **Sequential Processing:** Instead of taking the whole sequence at once, the RNN takes inputs one token/timestamp at a time ($x_1, x_2, \dots, x_t$).
2. **Recurrent Formula (The Memory Update):** At any time step $t$, the network calculates its current hidden state $h_t$ using the current input $x_t$ and the *previous* hidden state $h_{t-1}$:

$$h_t = \tanh(W \cdot x_t + U \cdot h_{t-1} + b)$$


* $W$ and $U$ are weight matrices (the parameters the network adjusts to learn).
* $b$ is the bias vector.
* $\tanh$ is an activation function squishing values between $-1$ and $1$.


3. **Output Generation:** If needed, an output $y_t$ can be calculated at each step using the updated memory: $y_t = \text{softmax}(V \cdot h_t + c)$.
4. **Parameter Sharing:** The exact same weights ($W, U, V$) are reused at every single time step. This allows the network to look for patterns anywhere in the sequence without needing unique parameters for every position.

Before we write down the calculation for 2(c), **there is a noticeable dimensions typo in your professor's question paper.** Let’s look at the math layout carefully:

The equation inside the forget gate requires matrix multiplication:
